Connect ChatGPT for iOS to Lumiqot

Use ChatGPT Sites to set up a private connector for Lumiqot. Once you install the connector in ChatGPT, you can use the ChatGPT app on your iPhone to access your Lumiqot Remote MCP server.

Get your connection details

On your computer, open Lumiqot → Settings → Connect to Lumiqot Remote, choose Show iPhone QR Code, and scan it with your iPhone camera.

1. Create a private setup page

Review the first prompt, adjust it if needed, and send it in a ChatGPT Work conversation.

Use ChatGPT Sites to create a private MCP connector that only I can access. First, create a private setup page where I can enter my Lumiqot Remote MCP server URL and authorization token. Wait until I have entered both values before building the connector.

2. Enter your settings and build the connector

When the private setup page is ready, copy your server URL and authorization token from Get your connection details and enter them on the private setup page.

Then send the second prompt in the same ChatGPT Work conversation.

Build the private MCP connector. Forward each incoming MCP request to the configured Lumiqot Remote server URL and include the configured token in the Authorization header using the Bearer scheme. Store the token on the server and keep it out of client-side code. Verify that the Lumiqot Remote server returns its tool list in response to tools/list. Then register the connector as "Lumiqot" and show me the installation screen.

3. Install Lumiqot in ChatGPT

When the installation card appears in the chat, select Install. You can then use the Lumiqot connector in ChatGPT.
